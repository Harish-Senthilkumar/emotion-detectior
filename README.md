# Real-Time Facial Emotion Detector

A computer vision application built in VS Code using OpenCV and Deep Learning to predict facial expressions from a webcam stream.

## 🛠️ Setup Instructions
1. Initialize environment: `python -m venv venv`
2. Activate environment: `source venv/bin/activate` or `.\venv\Scripts\activate`
3. Install packages: `pip install -r requirements.txt`
4. Run application: `python src/detector.py`
